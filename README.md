# 酸鹼實驗室

國中自然第 4 冊「電解質及酸鹼反應」的互動學習網站。七個實驗站，每一站都有可以動手操作的小實驗。

| 站 | 主題 | 互動內容 |
|---|---|---|
| 01 | 電解質 | 導電實驗：九種物質放進燒杯，看燈泡亮不亮 |
| 02 | 解離與離子 | 選電解質、調整數量，觀察離子個數與總電量 |
| 03 | 常見的酸與鹼 | 藥品櫃：性質、俗名、用途與酸鹼通性對照 |
| 04 | pH 與指示劑 | pH 滑桿、三種指示劑變色、稀釋實驗、莫耳濃度小算盤 |
| 05 | 酸鹼中和 | 滴定模擬：離子數量、溫度曲線、鹽酸／硫酸比較 |
| 06 | 鹽類 | 五種常見的鹽、蘇打與小蘇打對照 |
| 07 | 總測驗 | 12 題即時解析，答錯會指回對應的實驗站 |

## 使用方式

純靜態網頁，沒有建置步驟，也不需要伺服器。

- 本機：直接用瀏覽器開啟 `index.html`
- GitHub Pages：到 repo 的 Settings → Pages，Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`

## 檔案

```
index.html        頁面內容
assets/style.css  樣式
assets/app.js     互動邏輯（無外部相依）
```

學習進度與測驗最佳成績只存在瀏覽器的 localStorage，不會上傳。

## 說明

內容依 108 課綱國中自然科編寫，題目與文字皆為原創。滴定模擬的溫度以中和熱約 57 kJ/mol、溶液比熱 4.18 J/g·℃ 估算，僅供觀察趨勢。
